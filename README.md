## 📌 Ringkasan Proyek

Dashboard menampilkan gambaran tenaga kerja dari tiga sudut pandang: halaman **Home** sebagai navigasi, halaman **Summary** untuk ringkasan KPI, dan halaman **Detail** untuk penelusuran lebih dalam.

## 🎯 Tujuan

- Menyajikan KPI SDM dalam tampilan yang mudah dibaca.
- Membantu tim HR memantau kondisi karyawan.
- Membandingkan hasil visualisasi di Tableau dan Power BI.

## 🛠️ Tools

- **Tableau**
- **Power BI** (`.pbix`)
- **Microsoft Excel** sebagai sumber data

## 📁 Struktur Repository

```
HR-Dashboard-tableau/
├── HR Data.xlsx               # Dataset HR
├── HR Analytic Dashboard.pbix # File dashboard Power BI
├── Tableau Dashboard.png      # Tampilan dashboard Tableau
├── HR Home Dashboard.png      # Halaman Home (Power BI)
├── HR Summary Dashboard.png   # Halaman Summary (Power BI)
├── HR Detail Dashboard.png    # Halaman Detail (Power BI)
└── README.md
```

## 🚀 Cara Menggunakan

1. Download repository ini.
2. Buka `HR Analytic Dashboard.pbix` dengan **Power BI Desktop**.
3. Untuk versi Tableau, hubungkan **Tableau** ke `HR Data.xlsx` dan lihat `Tableau Dashboard.png` sebagai acuan tampilan.
